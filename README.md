# Modern Work Atlas

PORTFÓLIO PROFISSIONAL — EXPERIÊNCIA VISUAL IMERSIVA

OBJETIVO

Desenvolver um portfólio profissional moderno, impactante e altamente interativo, com uma identidade visual tecnológica e sofisticada.

Quero um site que fuja dos portfólios tradicionais.

A experiência deve transmitir criatividade, domínio tecnológico, capacidade de desenvolvimento e atenção aos detalhes.

O visitante deve sentir que está navegando por uma experiência digital cuidadosamente projetada, e não apenas por uma página com textos e cards.

Referência de qualidade: sites premiados no Awwwards, portfólios de desenvolvedores criativos e experiências digitais da FIAP.

Não copiar nenhum site. Utilizar essas referências apenas como inspiração para criar uma identidade própria.
